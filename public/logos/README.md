# Brand artwork

The 76 logos use original colored SVG artwork on light backgrounds. Multicolor
marks retain their individual fills and gradients. Single-color marks retain
the supplied path geometry and use the brand color documented by Simple Icons.
Brands with dark primary marks remain dark.

`SOURCES.json` records the official brand source and artwork source for each file.
Artwork is bundled locally; the UI does not tint, grayscale, or fetch logos from
third-party image services.
